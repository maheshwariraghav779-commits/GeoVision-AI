# Machine Learning

This folder contains the machine-learning experiments for GeoVision AI.

## Initial Model

The first model will use Random Forest for binary classification:

- 0 = No significant change
- 1 = Significant vegetation loss

## Input

The model uses features derived from Sentinel-2 imagery and environmental indices generated by Google Earth Engine.

Feature groups include:

- Sentinel-2 spectral bands
- NDVI
- NDWI
- NDBI
- Multi-temporal change features

## Initial Dataset

The current experimental dataset contains 5,000 spatial samples generated for a selected Area of Interest.

Class distribution:

- Class 0: 2,500 samples
- Class 1: 2,500 samples

## Planned Evaluation

The model will be evaluated using:

- Precision
- Recall
- F1-score
- Confusion matrix
- Feature importance

Accuracy will not be used as the only performance measure.

## Research Consideration

The initial labels are derived from a rule-based vegetation-loss baseline. Therefore, the first experiment evaluates how well machine learning reproduces the baseline pattern.

A leakage-controlled experiment will subsequently exclude the variables directly used to construct the baseline label.
